# UPI Transactions Dashboard

## 📊 Project Overview

The UPI Transactions Dashboard is an interactive data visualization project created to analyze and monitor UPI transaction data.

The dashboard provides a complete overview of transaction performance, including total transactions, transaction amount, cashback, success rate, suspected fraud, UPI applications, banks, transaction types, states, and time-based transaction patterns.

The main purpose of this project is to convert raw UPI transaction data into meaningful and easy-to-understand visual insights.

---

## 🎯 Objectives

The main objectives of this project are:

- To analyze the overall UPI transaction volume.
- To monitor the total transaction amount.
- To calculate and display the transaction success rate.
- To analyze transactions based on UPI applications.
- To compare transaction amounts across different banks.
- To analyze transaction amounts across different Indian states.
- To understand different transaction types.
- To identify transaction patterns by hour and day.
- To monitor suspected fraudulent transactions.
- To provide an interactive dashboard for data analysis and decision-making.

---

## 📈 Dashboard Features

### 1. Transactions Amount Over Time

This line/area chart shows the transaction amount for each day of the month.

It helps identify:

- Daily transaction trends
- High transaction days
- Low transaction days
- Changes in transaction activity over time

---

### 2. Transactions by UPI App

A donut chart is used to compare transaction activity across different UPI applications.

The dashboard includes:

- PhonePe
- Google Pay
- Paytm
- Amazon Pay
- BHIM
- Cred Pay
- WhatsApp Pay

PhonePe has the highest displayed share, followed by Google Pay and Paytm.

---

### 3. Transactions by Status

This donut chart shows the distribution of transactions according to their status.

The categories include:

- Success
- Failed
- Pending
- Refunded

The dashboard shows a success rate of approximately 91%, indicating that most transactions were successfully completed.

---
