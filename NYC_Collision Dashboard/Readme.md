# 🚦 NYC Collision Dashboard

An interactive **NYC Collision Analysis Dashboard** created to analyze motor vehicle collisions across New York City. The dashboard provides insights into collision frequency, fatalities, injuries, vehicle types, risky time periods, borough-wise distribution, and high-risk streets.

---

## 📊 Dashboard Overview

The dashboard provides a visual analysis of NYC collision data and helps identify:

- High-risk boroughs
- High-risk streets
- Common vehicle types involved in collisions
- Collision patterns by time of day
- Fatalities and injuries
- Risky periods for collisions

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze the total number of NYC collisions.
- Identify boroughs with the highest collision counts.
- Analyze collisions by vehicle type.
- Identify high-risk time periods.
- Analyze injuries and fatalities.
- Identify streets with the highest number of collisions.
- Highlight high-risk areas and periods.
- Provide data-driven road safety recommendations.

---

## ⏰ Collision Analysis by Time of Day

The dashboard categorizes collisions into four major time periods:

| Time Period | Collision Share |
|---|---:|
| Morning | **26.60%** |
| Afternoon | **28.93%** |
| Evening | **21.64%** |
| Night | **22.83%** |

### Key Insight

**Afternoon** has the highest collision share at **28.93%**.

The dashboard also identifies **Friday 4 PM - 8 PM** as the risky time period.

### Recommendation

Traffic control, visibility measures, and road-safety monitoring should be strengthened during high-risk periods.
