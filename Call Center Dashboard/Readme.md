
# 📊 Call Center Dashboard

An interactive **Call Center Dashboard** designed to analyze call performance, customer reach, deal closures, and sales agent productivity. This dashboard provides a clear overview of key performance indicators (KPIs) and helps track performance across weekdays, months, and quarters.

## 📸 Dashboard Preview

![Call Center Dashboard](images/call-center-dashboard.png)

## 🎯 Project Objectives

- Monitor total calls and calls reached.
- Track the number of deals closed.
- Analyze total deal value.
- Compare performance across weekdays, months, and quarters.
- Evaluate individual sales agent performance.
- Identify trends and opportunities for improvement.

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- **Total Calls:** Displays the total number of calls made.
- **Total Calls Reached:** Shows the number of calls that successfully reached customers.
- **Total Deals Closed:** Displays the number of successfully closed deals.
- **Total Deal Values:** Shows the total monetary value of deals.

The KPI cards also display percentage and absolute changes compared with the last month.

## 📈 Dashboard Features

### 1. Weekday Performance Chart
Analyzes call activity and deal performance from Monday to Sunday to identify the most productive days.

### 2. Monthly Performance Chart
Displays monthly performance from January to December, allowing users to compare calls reached and deals closed over time.

### 3. Quarterly Performance Chart
Provides a quarterly summary to compare performance across different periods.

### 4. Sales Agents KPI View
Displays individual sales agent performance using the following metrics:

- Full Name
- Total Calls
- Calls Reached
- Deals Closed
- Deal Value ($)

The dashboard includes three categories:
- High Volume Deals
- Low Volume Deals
- No Deals

### 5. Year Filter
Allows users to filter dashboard data by year, such as 2023 and 2024.

### 6. Month Filter
Allows users to select individual months for focused performance analysis.
