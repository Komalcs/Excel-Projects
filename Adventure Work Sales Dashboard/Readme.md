# 📊 Adventure Works Sales Analysis Dashboard

## 📌 Project Overview

The **Adventure Works Sales Analysis Dashboard** is an interactive sales and profitability analysis project created to transform raw business data into meaningful and actionable insights.

The dashboard provides a comprehensive view of **sales, revenue, profit, products, customers, pricing, transactions, time-based performance, and geographical analysis**.

---

## 🎯 Objectives

- Analyze overall sales and profitability performance.
- Identify the most profitable products.
- Identify the top-performing customers.
- Analyze profit by product color.
- Compare profit based on product pricing.
- Analyze profit contribution by gender.
- Track revenue, COGS, profit, and profit margin.
- Analyze monthly, quarterly, and yearly performance.
- Compare weekday and weekend profitability.
- Analyze business performance across different countries.
- Create an interactive and user-friendly business dashboard.
